# Film Censor

**Film Censor** — это веб-приложение для поиска фильмов и публикации рецензий. Проект объединяет базу данных фильмов (через интеграцию с внешним API) и систему пользовательских отзывов.

## Основные возможности

- **Поиск фильмов**: Поиск по названию с использованием Kinopoisk.dev API.
- **Просмотр деталей**: Подробная информация о фильмах, рейтингах и актерах.
- **Рецензии**: Авторизованные пользователи могут оставлять отзывы и ставить оценки фильмам.
- **Личный кабинет**: Регистрация и аутентификация пользователей.
- **Адаптивный интерфейс**: Удобная работа как на десктопах, так и на мобильных устройствах.

## Технологический стек

### Backend
- **FastAPI**: Современный и быстрый Python-фреймворк для создания API.
- **SQLAlchemy**: ORM для взаимодействия с базой данных.
- **PostgreSQL**: Реляционная база данных для хранения пользователей и отзывов.
- **JWT**: Аутентификация на основе токенов.
- **Kinopoisk.dev API**: Источник данных о фильмах.

### Frontend
- **React 19**: Библиотека для создания пользовательских интерфейсов.
- **TypeScript**: Строгая типизация для повышения надежности кода.
- **Vite**: Быстрая сборка фронтенда.
- **TailwindCSS**: Современный CSS-фреймворк для стилизации.
- **React Router**: Навигация в приложении.
- **Axios**: HTTP-клиент для связи с бэкендом.

## Запуск проекта

Самый простой способ запустить проект — использовать Docker Compose.

### Предварительные требования
- Docker
- Docker Compose

### Шаги для запуска

1. Склонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd film-censor
   ```

2. Запустите контейнеры:
   ```bash
   docker-compose -f deploy/docker-compose.yaml up --build
   ```

3. После завершения сборки:
   - Frontend будет доступен по адресу: `http://localhost`
   - Backend API будет доступен по адресу: `http://localhost:8000`
   - Документация API (Swagger): `http://localhost:8000/docs`

## Структура проекта

- `backend/` — Исходный код серверной части (FastAPI, модели БД, логика аутентификации).
- `frontend/` — Исходный код клиентской части (React компоненты, страницы, стили).
- `deploy/` — Конфигурационные файлы для развертывания (Docker Compose).
